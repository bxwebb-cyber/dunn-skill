# Dunn: get paid on time

An agent skill for exact invoice due dates (Net 30, 60, 90, EOM), late fees, how late an invoice is, and payment reminder emails, using [Dunn](https://getdunn.org)'s free tools. No login or API key needed.

## Install

```bash
npx skills add bxwebb-cyber/dunn-skill
```

## What's inside

- `skills/get-paid-on-time/SKILL.md`: when and how to use Dunn's four free tools.

The tools run at `https://getdunn.org/mcp` and store nothing.
